副業エンジニアにとって確定申告は、本業の給与と個人事業の売上・経費を分けて整理し、青色申告の帳簿づけから e-Tax 提出までを「開発スプリント外の大型タスク」として抱えがちです。クラウド請求で出した売上をどう仕訳するか、レシートやサブスク代をいつ拾うか、消費税やインボイスを自分で申告する必要があるか——ツール選びを誤ると、毎年同じ迷いが繰り返されます。[請求書ツールの選び方については別記事で比較しています](/posts/freelance-invoice-tool-comparison)。ここでは公開情報ベースで **freee会計**・**やよいの青色申告 オンライン**・**マネーフォワード クラウド** の3サービスを整理します。

## 選定基準（何を比較するか）

副業エンジニアが確定申告ソフトを選ぶとき、次の軸が実務上効きやすいです。

- **料金**：年払い・月払いの差、初年度無料やトライアルの有無、消費税申告が別プランか
- **青色申告・帳簿**：仕訳の自動化、銀行・クレジットカード連携、レシート取込の上限
- **申告書作成・提出**：所得税の確定申告書類、e-Tax（電子申告）対応
- **副業・フリーランス向け運用**：請求書連携、複数口座、本業給与との所得区分（雑所得・事業所得などは申告内容次第）
- **サポート**：チャット・電話、操作質問と税務相談の範囲の違い

以下の比較表と各サービス解説は、各社公式サイト等で公開されている情報をもとにしています。キャンペーンや価格改定で変わる場合があるため、契約前は必ず最新の料金ページを確認してください。

## freee会計

### 概要・料金

freee会計は、個人事業主向けに **スターター**・**スタンダード**・**プレミアム**（ほか **入力おまかせ** 等）のプランが公式に案内されています。個人事業主向け料金表では、スターターが **年払い 980円/月（年額11,760円）**、**月払い 1,780円/月** など、スタンダードが **年払い 1,980円/月（年額23,760円）**、**月払い 2,980円/月** など（いずれも税抜の表示例）とされています。スターターでは確定申告書類の作成、レシート撮影（月5枚まで等）、銀行・クレジット明細取得、見積・請求書作成などが訴求され、**消費税申告（インボイス制度対応）** はスタンダード以上の機能として案内されています。最大約1か月のお試し後に無料プランへ移行する仕組みなど、公式ヘルプで機能制限の詳細が説明されています。

### メリット

- 副業から事業規模が伸びても、プランアップで消費税申告やレシート取込上限の拡張がしやすい
- **freee請求書** など freee 製品群と連携し、売上〜仕訳〜申告まで一本化しやすい（連携条件は各サービスの契約内容による）
- API や開発者向け連携を含む freee エコシステムを、エンジニア視点で拡張しやすい点が検討材料になりやすい

### デメリット

- 消費税申告やレシート大量取込まで含めるとスタンダード以上が必要になり、スターターだけでは足りないケースがある
- プラン数とオプションが多く、初年度は公式のプラン比較表を読み込む時間がかかりやすい

## やよいの青色申告 オンライン

### 概要・料金

**やよいの青色申告 オンライン** は、弥生のクラウド型青色申告ソフトです。公式の料金ページでは **セルフ**・**ベーシック**・**トータル** の3プランがあり、**機能内容はプラン共通**で、主な違いはサポート範囲（Web FAQ のみ／操作質問の電話・メール・チャット／仕訳・経理・確定申告相談など）とされています。表示例として、セルフはキャンペーン時 **1年間無料** のあと **年額11,800円+税**、ベーシックは同様に初年度無償キャンペーン後 **年額22,800円+税**、トータルは **初年度19,800円+税**・次年度以降 **年額39,600円+税** など（価格改定・適用時期は公式のお知らせ参照）。確定申告書の作成・e-Tax、金融機関連携、請求書連携、スマホアプリなどが全プランで利用できると案内されています。

### メリット

- 青色申告に特化した UI で、帳簿〜申告まで弥生ブランドで揃えやすい
- 機能差がサポート中心のため、「まずセルフで試し、困ったらベーシックへ」という段階的な選び方がしやすい
- **Misoca** 等の弥生請求サービスとの連携を公式に訴求しており、請求と申告の役割分担を検討しやすい

### デメリット

- 白色申告のみ・給与所得だけの人向けではなく、青色申告前提の製品設計
- キャンペーン終了後の更新価格や改定時期は時期により変わるため、申込前に公式の価格改定情報を確認する必要がある

## マネーフォワード クラウド

### 概要・料金

**マネーフォワード クラウド** は、個人事業主向けのクラウド確定申告ソフトです。公式の料金ページでは **パーソナルミニ**・**パーソナル**・**パーソナルプラス** などが案内されています。例として、パーソナルミニは **年払い 900円/月（一括10,800円/年）**、**月払い 1,280円/月**、パーソナルは **年払い 1,280円/月（15,360円/年）**、**月払い 1,680円/月**、パーソナルプラスは **年払いのみ 2,980円/月（35,760円/年）** など（税抜）。ミニプランでは確定申告書類の作成（青色・白色）・電子申告・明細自動取込などが案内される一方、**消費税申告は利用できない** と公式に記載されています。パーソナルプラン相当の **1か月無料トライアル**（自動課金なし、データ引き継ぎあり等）や、事業者登録のみの無料利用範囲についても公式トピックスで説明されています。

### メリット

- **マネーフォワード クラウド請求書** や MF クラウド会計系と ID を揃え、請求〜入金〜申告の流れを統一しやすい
- 年払いミニプランは税抜900円/月相当からと公式に案内され、所得税の申告中心ならコストを抑えやすい
- レシート撮影（件数上限はプラン・公式注記参照）や契約書作成など、副業のバックオフィスを広げやすい

### デメリット

- インボイス対応の消費税申告まで含めるとパーソナル以上が必要で、ミニだけでは不足しやすい
- キャンペーン（トライアル、月額割引等）は時期限定のため、申込タイミングで実質コストが変わる

## まとめ

- **freee 請求書などとセットで freee 内に寄せたい** → **freee会計**（消費税まで見るならスタンダード以上を公式表で確認）
- **弥生系で青色申告をシンプルに、初年度はコストを抑えたい** → **やよいの青色申告 オンライン**（セルフ〜、サポートが必要ならベーシック）
- **マネーフォワード クラウド請求書を使っている／使う予定で MF に統一したい** → **マネーフォワード クラウド**（消費税なしならミニ、必要ならパーソナル以上）

副業エンジニアは「今年の売上規模」「消費税申告の要否」「請求ツールとの連携先」をセットで決めると選びやすいです。いずれも公式の最新料金と機能表を確認したうえで、銀行連携と1ヶ月分の仕訳テストまで試すのがおすすめです。
